# Agent guidance

For Axolotl-PM and PocketMine-MP plugin work, follow the [AxolotlBucketLabs skill](https://github.com/AxolotlBucketLabs/axolotl-bucket-labs/blob/main/SKILL.md). Read its [writing style reference](https://github.com/AxolotlBucketLabs/axolotl-bucket-labs/blob/main/references/writing-style.md) before writing human-facing prose.

Write directly with complete sentences. Avoid em dash and en dash punctuation and semicolons in prose. Use inline code for paths, commands, identifiers, and configuration keys.
