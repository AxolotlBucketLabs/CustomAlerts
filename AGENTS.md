# Axolotl-PM agent guidance

Use the [AxolotlBucketLabs skill](https://github.com/AxolotlBucketLabs/axolotl-bucket-labs/blob/main/SKILL.md) for Axolotl-PM and PocketMine-MP plugin work. Read its [writing style](https://github.com/AxolotlBucketLabs/axolotl-bucket-labs/blob/main/references/writing-style.md) before writing human-facing prose.

Write natural, complete sentences. Do not use em dash or en dash punctuation or semicolons in prose. Avoid unnecessary `Label: content` phrasing. Use straight double quotes and Markdown inline code for technical names and paths. Start standalone bullets with a capital letter and end them with a period.
